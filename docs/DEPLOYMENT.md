# دليل النشر — متجر شركة الصفا للتوريدات الكهربائية

دليل خطوة بخطوة لنشر المتجر على استضافة مشتركة (cPanel). مكتوب بلغة بسيطة، وكل خطوة فيها «ليه» باختصار عشان لو حاجة وقفت تعرف السبب.

- الكود موجود على GitHub في مستودع **HadyAbdelmonem/almotaheda_site** (الفرع الرئيسي `main`).
- المتجر مبني بـ Laravel 13 ويحتاج: **PHP 8.3 أو أحدث**، وقاعدة بيانات **MySQL 8**، وشهادة **SSL** (HTTPS).

---

## ⚠️ خطوة إلزامية قبل الإطلاق: إعادة التحقق على MySQL

أثناء التطوير، الاختبارات اتعملت على قاعدة SQLite المحلية. قبل ما المتجر يستقبل طلبات حقيقية، لازم على بيئة تجريبية (Staging) بنفس نسخة MySQL 8 اللي على الاستضافة:

1. تشغيل `php artisan test` كاملة على MySQL.
2. التأكد يدويًا من اختبارات التزامن (حجز المخزون وحد استخدام الكوبونات) — لأن سلوك القفل `lockForUpdate` والأرقام العشرية `decimal` بيختلف بين قواعد البيانات.

**متفتحش المتجر للبيع قبل الخطوة دي.**

---

## 1) تجهيز الاستضافة

1. من cPanel افتح **Select PHP Version** واختار **PHP 8.3+**، وفعّل الإضافات دي:
   `bcmath, gd, intl, mbstring, curl, zip, exif, pdo_mysql, fileinfo, openssl, dom, xml, tokenizer, ctype, iconv, simplexml, xmlreader, zlib`
   (إضافة gd لازم تدعم WebP — دي اللي بتولّع صور المنتجات بصيغة WebP الخفيفة).
2. من **MySQL Databases** اعمل قاعدة بيانات جديدة + مستخدم بكلمة مرور قوية، وادّي المستخدم كل الصلاحيات على القاعدة.
3. فعّل **SSL** من قسم Security » SSL/TLS (شهادة Let's Encrypt المجانية كفاية).

## 2) رفع الكود

عندك طريقتين — اختار واحدة:

**أ) من Git (الأسهل للتحديثات):** لو الاستضافة فيها Terminal:
```bash
cd ~
git clone https://github.com/HadyAbdelmonem/almotaheda_site.git store
cd store
```

**ب) رفع يدوي:** نزّل الكود من GitHub كملف ZIP وارفعه من File Manager وفكّه في مجلد وليكن `store` **برّه** مجلد `public_html`.

## 3) توجيه الدومين لمجلد public (مهم جدًا للأمان)

لازم موقعك يقرأ من مجلد `public` جوه المشروع فقط، مش من جذر المشروع — عشان ملفات زي `.env` متبقاش مكشوفة على الإنترنت.

- من cPanel » Domains » الدومين » Document Root: خلّيه `store/public`.
- لو الاستضافة مش بتسمح بتغيير الـ Document Root: انقل محتويات مجلد `public` إلى `public_html` وعدّل في `public_html/index.php` المسارين بتوع `vendor/autoload.php` و `bootstrap/app.php` عشان يشاوروا على مكان المشروع الحقيقي.

## 4) إعداد ملف البيئة .env

```bash
cd ~/store
cp .env.production.example .env
```
عدّل في `.env` القيم دي بس:
- `APP_URL` = رابط موقعك الحقيقي بـ https.
- `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` = بيانات القاعدة اللي عملتها.
- بيانات البريد `MAIL_*` لو عايز إشعارات بريد (اختياري).
- **سيب مفاتيح Paymob فاضية** — مفيش حساب تاجر حاليًا، والدفع بالبطاقة مقفول. الدفع المتاح: عند الاستلام + تحويل بنكي (InstaPay / فودافون كاش).

وبعدين ولّد مفتاح التطبيق:
```bash
php artisan key:generate
```

## 5) تثبيت الحزم وبناء الواجهة

على الاستضافة (لو Composer متاح):
```bash
composer install --no-dev --optimize-autoloader
```

ملفات الواجهة (CSS/JS) بتتبني على جهازك المحلي مش على السيرفر:
```bash
npm install
npm run build
```
وبعدين ارفع مجلد `public/build` الناتج زي ما هو للمشروع على السيرفر.

> لو Composer مش متاح على الاستضافة: شغّل `composer install --no-dev` على جهازك وارفع مجلد `vendor` كامل.

## 6) إنشاء الجداول وبيانات الأساس (ProductionSeeder فقط)

```bash
php artisan migrate --force
php artisan db:seed --class=ProductionSeeder --force
php artisan storage:link
php artisan optimize
```

`ProductionSeeder` بيحط بس الأساسيات: إعدادات المتجر بهوية **شركة الصفا للتوريدات الكهربائية** (الاسم، العنوان: التجمع الخامس، القاهرة، أرقام التواصل، التحويل البنكي، صفحة فيسبوك)، أسعار الشحن للمحافظات الـ27، الأقسام، الماركات، والصفحات الثابتة.
**مفيش منتجات تجريبية ومفيش كلمة مرور أدمن معروفة في الـ ProductionSeeder.**

> ⚠️ ممنوع تمامًا تشغيل `migrate:fresh` على قاعدة فيها بيانات حقيقية — الأمر ده بيمسح كل حاجة. هو معمول بس لبيئات التطوير والاختبار المحلية.

## 7) إنشاء حساب الأدمن

```bash
php artisan tinker
```
```php
$u = new App\Models\User;
$u->forceFill(['name' => 'المدير', 'email' => 'your-email@example.com', 'password' => 'كلمة-مرور-قوية-جدًا', 'is_admin' => true])->save();
```
- ادخل لوحة التحكم من `https://your-domain.com/admin`.
- **تدوير كلمة المرور:** غيّر كلمة مرور الأدمن أول مرة تدخل، وبعدها بشكل دوري، ومتشاركهاش مع حد. (حقل `is_admin` مش قابل للتعيين من أي فورم — ده مقصود للأمان.)

## 8) الـ Cron Jobs (مهمة جدًا)

من cPanel » Cron Jobs أضف السطر ده يشتغل **كل دقيقة**:
```bash
cd ~/store && php artisan schedule:run >> /dev/null 2>&1
```
ده بيشغّل مهام مجدولة أهمها: انتهاء طلبات الدفع بالبطاقة غير المدفوعة بعد 60 دقيقة (لو اتفعّلت البطاقة مستقبلًا). طلبات التحويل البنكي **مش** بتنتهي تلقائيًا أبدًا — بتفضل محجوزة لحد ما الأدمن يلغيها يدويًا.

## 9) صلاحيات المجلدات

لازم السيرفر يقدر يكتب في:
```bash
chmod -R 775 storage bootstrap/cache
```
ومجلد `storage/app/private` بيخزن إيصالات التحويل البنكي — دي ملفات **خاصة** ومتاحة بس من خلال لوحة التحكم بعد تسجيل الدخول، وممنوع تبقى في مجلد عام.

## 10) النسخ الاحتياطي

- من cPanel » Backup: نزّل نسخة من قاعدة البيانات + مجلد المشروع أسبوعيًا على الأقل، واحتفظ بنسخة برّه الاستضافة.
- جرّب الاسترجاع مرة على بيئة تجريبية قبل ما تحتاجه فعلًا.

## 11) أماكن اللوجات (لو حصلت مشكلة)

- أخطاء التطبيق: `storage/logs/laravel.log`
- عمليات الدفع: `storage/logs/payments.log` (بيانات حساسة زي أرقام البطاقات أو مفاتيح الدفع **مش** بتتكتب هناك أبدًا — بتتشال تلقائيًا قبل الحفظ).

## 12) تحديث المتجر بعد كده

```bash
cd ~/store
git pull
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan optimize
```
وارفع `public/build` الجديد لو الواجهة اتغيرت.

## 13) حذف البيانات التجريبية (لو رفعت نسخة تجريبية بالغلط)

```bash
php artisan store:purge-demo
```
الأمر ده بيمسح المنتجات والطلبات والكوبونات التجريبية بس، وبيسيب الإعدادات والأقسام وأسعار الشحن. على بيئة الإنتاج بيطلب `--force` وتأكيد كتابي — مش بيشتغل بالغلط.

## ✅ قائمة اختبار سريعة بعد النشر (Smoke Test)

- [ ] الصفحة الرئيسية تفتح بـ HTTPS من غير تحذيرات.
- [ ] قسم وماركة ومنتج بيفتحوا، والبحث بيشتغل بالعربي وبكود الموديل.
- [ ] إضافة منتج للسلة (منهم منتج بيتباع بالمتر بكمية كسرية) وإتمام طلب تجريبي «الدفع عند الاستلام».
- [ ] الطلب ظهر في لوحة التحكم، وتغيير حالته بيشتغل، والفاتورة بتتطبع صح.
- [ ] طلب «تحويل بنكي» + رفع إيصال من صفحة تتبع الطلب، والإيصال بيظهر للأدمن بس.
- [ ] زر واتساب بيفتح الرقم الصحيح `01033808633`.
- [ ] تتبع الطلب برقم الطلب + رقم الموبايل بيشتغل، وبرقم غلط بيدي رسالة عامة.
- [ ] تجربة كاملة من موبايل حقيقي (دي أهم خطوة — أغلب العملاء موبايل).
